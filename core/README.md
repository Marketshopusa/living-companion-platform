# Companion Core

Canonical domain. Gate 1 implements **identity contracts only**.

- Contracts: `core/contracts/identity/v1/` (JSON Schema, language-neutral)
- Runtime adapter (ADR-001): `core/identity/` (Python validation, policy, commands)
- Persistence port: `backend/identity/` (in-memory and optional JSON files)

Not started: memory, relationship, personality engine behavior, emotion, physical state, outfit, world pointers, entitlements, AI configuration.
