# Environments

| Name | Purpose | Gate 0 |
| --- | --- | --- |
| `local` | Developer machine, $0, no paid APIs | **Active** |
| `staging` | Shared non-production (future) | Not created |
| `prod` | Production (future) | Not created |

No cloud accounts, GPU providers, or paid subscriptions are provisioned in Gate 0.

Copy `.env.example` to `.env` locally when application code exists. Never commit `.env`.
